# ESS 배터리 수명 예측

충전·방전 초기 100사이클의 측정값만으로 리튬이온 셀의 수명(Cycle Life)을 예측한다. 수명이 다하기 전에 셀을 선별하고 교체를 계획하는 데 쓸 수 있는 조기 신호를 찾는 것이 목적이다. 설계 단계에서 EDA로 세운 모델 설계를 그대로 구현하고, 후보 모델을 비교해 최종 모델을 고른 뒤 원논문 성능과 비교한다.

## 프로젝트 개요

- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터 : Batch 1 (2017-05-12)
- 평가 데이터 : Batch 2 (2018-02-20), 추가 검증 Batch 3 (2018-04-12)
- 태스크 : **Regression** (Cycle Life 예측)
- 최종 모델 : **Ridge Regression** (α=0.01), 입력 **ΔQ 로그분산 1개**, 타깃 cycle_life

## EDA

분석 대상은 수명 라벨이 있는 129셀(Batch 1/2/3 = 46/39/44)이다. 제외한 10셀은 수명 기록이 없는 셀로, VarCharge·SLOWCYCLE 실험 8셀과 Batch 3의 2셀이다.

- **Cycle Life 분포**
  - 관찰 : 수명 중앙값 858 / 472 / 1,006회. 550회 미만 셀 수는 1 / 30 / 1셀
  - 핵심 발견 : 학습 배치(Batch 1)에 단수명 셀이 1개뿐이고, Batch 2 대부분은 Train 수명 범위(599~1,227회)보다 짧음
  - **판단** : 분류 대신 **회귀**를 택함. 학습 범위 밖으로도 예측할 수 있는 **선형 모델**을 주 후보로 둠
- **열화 곡선 분석**
  - 관찰 : 후반 기울기가 2배 이상 가팔라지는 셀이 42/46, 39/39, 43/44개. Knee 중앙값 645 / 360 / 810회
  - 핵심 발견 : 100회까지는 장수명·단수명 셀의 용량 곡선이 거의 겹치고, Knee는 수명 후반에야 나타남
  - **판단** : Knee와 101회 이후 값은 입력에서 제외함. 용량 값 대신 **방전 곡선 모양의 변화**에서 피처를 찾음
- **ΔQ(V) 곡선 분석**
  - 관찰 : 세 배치 모두 수명 하위 1/3의 ΔQ(V) = Q100(V) − Q10(V) 곡선이 상위 1/3보다 깊음
  - 핵심 발견 : ΔQ 로그분산과 수명의 순위상관이 −0.87 / −0.71 / −0.80으로, 세 배치에서 유지되는 유일한 신호. Batch 1에서는 거의 직선(Pearson −0.89)
  - 예시 : 1-21(534회)과 1-06(1,074회)은 수명이 2배 차이지만 100회차 용량은 1.061 / 1.080Ah로 2%도 차이 나지 않음. 그런데 ΔQ 곡선은 최대 −0.064 / −0.025Ah로 2.6배 차이 나고, ΔQ 로그분산은 −3.37 / −4.18
  - 도메인 해석 : 셀 내부가 상하기 시작하면(전극 표면 피막 성장, 쓸 수 있는 리튬 감소, 활물질 손실) 총 용량이 줄기 **전에** 특정 전압 구간에서 먼저 방전 곡선이 변형됨. ΔQ 로그분산은 이 초기 변형을 숫자 하나로 잡는 조기 경보
  - **판단** : **ΔQ 로그분산을 1순위 피처**로 두고, **Ridge 한 줄**에서 시작함
- **충전 속도(C-rate)와 수명의 관계**
  - 관찰 : Batch 1 정책별 평균 수명 약 546~1,226회. 첫 C-rate와 수명의 순위상관 −0.48 / +0.06 / −0.23
  - 핵심 발견 : 셀마다 다른 실험 조건은 충전 정책 하나뿐이라 정책이 수명의 핵심 원인임(Batch 1 정책 평균이 수명 차이의 93% 설명). 하지만 고속 충전일수록 짧다는 경향은 Batch 1에서만 뚜렷하고, 같은 정책도 셀마다 최대 234회 차이 남. 충전 전류와 C-rate는 Batch 1에서 같은 정보(ρ 0.97)
  - **판단** : 정책은 셀이 겪은 **조건(원인)**이고, ΔQ는 그 조건이 셀에 남긴 **결과**를 직접 잰 값. 충전 조건은 ΔQ에 더해 볼 **보조 후보**로만 두고, 전류와 C-rate 중 하나만 씀
- **피처 간 상관**
  - 관찰 : 평균·최고온도 ρ 0.96, ΔQ 분산·최솟값 ρ −0.99. 초기 용량 변화(+0.61 → −0.06)와 충전시간(+0.64 → −0.81)은 배치마다 상관이 사라지거나 뒤집힘
  - 핵심 발견 : 서로 겹치는 쌍이 있고, Batch 1에서만 유효한 신호가 많음
  - **판단** : 겹치는 쌍은 하나만 후보로 둠. 추가 피처는 **Batch 1 CV에서 오차가 실제로 줄 때만** 채택함
- **배치 간 Qdlin 비교 (추가)**
  - 관찰 : Batch 1만 46셀 전부 1회차 방전 용량이 0Ah인 빈 기록(Batch 2·3은 1.05~1.11Ah 실측). 10회차 기록의 충전 시작 전압·전류와 Q10 곡선 높이도 배치마다 다름
  - 검증 : Batch 1의 1회차가 빈 기록이면 "10·100회차"가 실제로는 9·99번째 방전일 수 있음. 그래서 129셀 모두 사이클 번호가 1부터 빠짐없이 이어지는지 확인함. 이어 원본에서 사이클 11·101을 직접 찾아 한 사이클 밀린 ΔQ(Q101 − Q11)를 다시 계산함
  - 핵심 발견 : 한 사이클을 밀어도 ΔQ 로그분산의 배치 평균 변화는 0.003 / 0.003 / 0.018, 수명과의 순위상관은 −0.871→−0.853, −0.709→−0.716, −0.797→−0.800. 배치 간 중앙값 차이(0.36)가 약 20배 큼. 다만 셀 하나 기준으로는 최대 0.2~0.35 움직임
  - **판단** : Qdlin 원본 대신 같은 셀·같은 전압 격자의 **ΔQ**를 쓰면 곡선 높이 차이는 상쇄되고, 번호 어긋남도 배치 수준 결론을 바꾸지 않음 → 별도 보정 없이 사이클 번호 기준으로 계산함. 남는 배치 간 차이는 측정 기록이 아니라 셀 자체의 차이로 보고 Batch 2 오차 분석에서 다시 확인함

## Modeling

### 피처 엔지니어링 전략

ΔQ 로그분산 하나에서 시작해 충전 전류, 온도·저항, 초기 용량 변화를 하나씩 더하며 Batch 1 Train의 정책 단위 4-fold CV로 검증했다. 셀 하나가 폴드 MAPE를 1%p 넘게 움직이므로, **CV가 0.5%p 이상 줄어야 피처를 채택**했다.

| 입력                                          |               CV MAPE | 판단 |
| --------------------------------------------- | --------------------: | ---- |
| 중앙값 기준선                                 |                19.65% | —    |
| ΔQ 로그분산                                   |             **8.98%** | 채택 |
| ΔQ + 충전 전류 / + 첫 C-rate                  |       10.11% / 10.11% | 기각 |
| ΔQ + 평균온도 / + 내부저항 / + 초기 용량 변화 | 9.35% / 9.68% / 8.96% | 기각 |

충전 정책은 수명의 핵심 원인이지만, 정책만으로 예측하면 CV가 14~15%로 ΔQ 하나(8.98%)보다 나쁘다. 정책 정보로는 처음 보는 정책의 수명이나 같은 정책 안의 셀 편차를 알 수 없기 때문이다. 정책의 영향은 이미 ΔQ에 결과로 담겨 있어, 더하면 정보가 중복되고 잡음만 늘었다(ΔQ + 정책 3요소 10.18%). 온도·저항·초기 용량 변화는 Batch 1에서만 상관이 보였고 CV 이득도 없었다. log10 타깃은 CV 10.95%로 원래 수명 타깃보다 나빠, 타깃은 cycle_life 그대로 쓴다.

### 모델 선택 및 근거

- 후보 모델 : 중앙값 기준선, **Ridge**, ElasticNet, 얕은 Random Forest
- 최종 모델 : **Ridge Regression (α=0.01)**, 입력 ΔQ 로그분산 1개
  - 학습된 식 : `cycle_life = −415.9 × ΔQ 로그분산 − 786.8`. ΔQ 로그분산이 0.1 커지면 예측 수명이 약 42회 줄어든다
- 선택 이유 :
  - Ridge와 ElasticNet은 CV 8.98%로 같다(입력이 하나라 두 모델이 같은 직선으로 수렴). 규칙에 따라 더 단순한 Ridge를 택했다.
  - RF는 11.11%로 더 나쁘다. 또 학습 수명 범위 밖(Batch 2 기존 절차 셀의 392~514회)을 예측할 수 없다.
  - 선정 규칙(최저 CV에서 0.5%p 이내면 단순한 모델)은 결과를 보기 전에 정했다. 피처·모델 선정은 Batch 1 Train CV 점수로만 했다. Batch 2·3은 EDA에서 피처 상관의 일관성을 볼 때만 참고했고, 그 성능 점수는 선정에 쓰지 않았다.

## 성능 결과

Batch 1 Train 37셀로 한 번 학습한 같은 모델로 평가했다. 분할은 정책 단위이며 Train 37셀(정책 18개, 4-fold) / Valid 9셀(정책 5개), random_state=42다.

| 구분                     |                     |  MAPE (%) | 비고                           |
| ------------------------ | ------------------- | --------: | ------------------------------ |
| Train (Batch 1 CV)       |                     |      8.98 | 정책 단위 4-fold 평균          |
| Valid (Batch 1 Hold-out) |                     |     10.38 | 학습에 없는 정책 9셀           |
| Test (Batch 2)           |                     | **33.04** | 39셀                           |
|                          | Gap (Train-Valid)   |     +1.40 | (+) : 과적합 의심              |
|                          | Gap (Valid-Test)    |    +22.66 | (+) : 배치간 일반화 저하 의심  |
|                          | Gap (Target-Test)   |    +23.94 | Target : 원논문 9.1%           |
| Test (Batch 3)           |                     | **12.85** | 44셀                           |
|                          | Gap (Batch2-Batch3) |    +20.19 | Test 성능 간 비교              |
|                          | Gap (Target-Test)   |     +3.75 | Batch 3 기준, 원논문 성능 비교 |

원논문이 제거한 Batch 3 노이즈 채널 4셀을 빼면 Batch 3 MAPE는 12.87%다(40셀). 결과에 거의 영향이 없다.

**Gap 해석**

- **Train-Valid +1.40%p** : 처음 보는 정책에서도 CV 수준을 유지한다. 피처가 하나라 과적합 징후는 작다.
- **Valid-Test +22.66%p** : 같은 배치 안의 일반화는 되지만, 다른 시기에 측정한 배치로 옮기면 오차가 3배가 된다.
- **Target-Test +23.94%p** : 대부분이 데이터 분할 방식의 차이다. 원논문은 Batch 1·2를 섞어 학습하고 같은 배치의 나머지 셀로 테스트했다. 같은 피처 1개 Ridge를 원논문처럼 섞어 분할하면 테스트 MAPE가 **12.7~14.7%**가 된다. 이는 원논문의 단일 ΔQ 모델(약 15%)과 같은 수준이다. 원논문의 9.1%와 약 15%의 차이(약 6%p)는 피처 수에서, 나머지 약 18%p는 **처음 보는 배치로 일반화하는 비용**에서 온다.
- **Batch2-Batch3 +20.19%p** : Batch 3은 전부 `newstructure`이고, Batch 2의 `newstructure` 9셀(14.1%)과 비슷하다. 차이의 대부분은 Batch 2 기존 절차 셀에서 오며, ΔQ 피처가 Batch 1에 과적합됐다는 근거는 약하다. Batch 3에서 학습 수명 범위 안에 있는 35셀은 **9.24%**로 원논문 수준이다.

## 오류 분석

- **Batch 2 기존 절차 30셀 (MAPE 38.7%, 과대예측)** : 가장 크게 틀린 2-07, 2-16(3.6C(9%)-5C), 2-19, 2-03(5.2C(50%)-4.25C)이 모두 여기에 속한다. ΔQ가 학습 범위 **안**에 있는 18셀이 오히려 더 크게 틀린다(45.6%). 같은 충전 정책이어도 Batch 2의 수명이 36~46% 짧다(6C(60%)-3C: 744 → 400회). 피처 외삽이 아니라 **같은 ΔQ에 대응하는 수명이 배치 수준에서 내려간 것**이다.
- **Batch 3 장수명 셀 (과소예측)** : 3-39(1,935 → 약 1,020회), 3-08, 3-46은 Train 최대 수명 1,227회를 넘는 셀이다. 범위 밖 9셀의 MAPE는 26.9%다.
- **원인 가설** : 사이클 번호 어긋남(01에서 원본으로 재계산해 배제)과 충전 정책 차이(같은 정책 비교)는 주원인이 아니다. 남는 후보는 측정 시기 차이 동안의 셀 상태 변화와 실험 조건 차이다. 이 데이터로는 둘을 분리할 수 없다.
- **개선 방향** : ① 여러 시기·절차의 배치를 섞어 학습한다. ② 오차가 기울기보다 절편 이동이므로, 새 배치의 수명 확정 셀 몇 개로 절편만 다시 맞춘다. ③ ΔQ·수명이 학습 범위를 벗어나면 예측과 함께 경고를 낸다.

## ESS 도메인 해석

- **활용** : 셀을 100사이클만 돌려 보고 수명을 예측할 수 있다. 같은 생산·시험 조건 안에서는 오차가 약 10%다(Valid 10.4%, Batch 3 범위 안 9.2%). 따라서 입고 셀 선별, 충전 정책 후보 비교, 교체 우선순위처럼 **같은 조건의 셀끼리 순위를 매기는 의사결정**에 쓸 수 있다.
- **한계** : 시기·절차가 바뀐 배치에서는 오차가 33%까지 커진다. 실험실 단일 셀의 급속 충전 시험 결과이므로 실제 BESS의 부분 충방전, 온도 편차, 모듈·랙 단위 셀 간 편차는 반영되지 않는다. Batch 1의 10셀(1-01~1-05, 1-09, 1-11, 1-13, 1-14, 1-23)은 용량이 0.88Ah에 닿기 전에 기록이 끝났다(마지막 용량 0.885Ah 초과). 그래서 cycle_life가 실제보다 짧게 잡혔을 수 있다. Day 1 설계대로 학습에 포함했고, 장수명 쪽 학습 범위를 좁히는 요인이다.
- **실 배포에 필요한 것** : 운영 조건과 같은 데이터로 재검증, 새 배치·현장 데이터에 대한 소수 셀 보정, 학습 범위 이탈 감지와 예측 불확실성 표시, 셀 단위 예측을 모듈·랙 단위로 확장하는 검증.
